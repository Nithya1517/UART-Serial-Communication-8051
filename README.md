# UART Serial Communication using 8051

## Project Overview
This project demonstrates UART serial communication using the AT89C51 microcontroller in Proteus simulation.

The microcontroller sends messages serially to a Virtual Terminal using UART protocol.

## Software Used
- Keil uVision
- Proteus 8 Professional

## Components Used
- AT89C51 Microcontroller
- Crystal Oscillator
- Capacitors
- Resistor
- Virtual Terminal

## UART Configuration
- Baud Rate: 9600
- Data Bits: 8
- Stop Bits: 1

## Output
The message "HELLO FROM 8051" is displayed continuously in the Virtual Terminal.
